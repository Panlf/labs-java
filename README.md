**labs-java** 是我日常学习 Java 的代码练习仓库。作为一个持续更新的技术实验场，它不仅包含了算法实现、语法验证，更涵盖了 **JUC 并发编程**、**NIO 网络模型**、**类加载机制**、**字节码操作**等底层原理的深入测试，同时记录了我在准备 Java 面试过程中积累的高频考点实战代码。

## ✨ 项目说明

- **📐 算法基石**：实现经典的最短路径（Dijkstra）等算法，巩固算法思维。
- **⚙️ JVM & 字节码**：深入研究自定义 `ClassLoader` 以及 `Javassist` 的字节码操纵。
- **🌐 高性能网络**：完整的 **NIO** 实践（Buffer/Channel/Selector），理解 IO 多路复用模型。
- **🔄 并发与多线程**：覆盖线程创建、通信、锁机制及线程池，专为应对高并发场景与**面试**设计。
- **🧩 设计模式**：从单例模式的多种写法入手，逐步掌握设计模式的核心思想与实战应用。
- **🎙️ 网络通信**：基于 Socket 实现 TCP/UDP 通信实战，包含简易聊天室案例。
